Topic 1: Stationary Points

Topic Overview & Definition

Definition: A stationary point (or critical point) of a function \( f(x) \) or multi-variable function \( f(x, y) \) is a point where the gradient/derivative of the function becomes zero.

Mathematical Condition:

  • For 1 Variable Function \( f(x) \): Set \( f'(x) = \frac{df}{dx} = 0 \).
  • For 2 Variable Function \( f(x, y) \): Simultaneously set \( f_x = \frac{\partial f}{\partial x} = 0 \) and \( f_y = \frac{\partial f}{\partial y} = 0 \).

Geometrical Meaning: At a stationary point, the tangent to the curve or tangent plane to the surface is perfectly horizontal (zero slope).

Topic 1: Stationary Points
Question 1: Find all stationary points for the single-variable function: \[ f(x) = 2x^3 - 9x^2 + 12x - 5 \]
Complete Step-by-Step Solution:
  1. Step 1: Compute the First Derivative
    Using standard differentiation rules:
    \( f'(x) = \frac{d}{dx}(2x^3 - 9x^2 + 12x - 5) = 6x^2 - 18x + 12 \)
  2. Step 2: Set Derivative to Zero
    \( 6x^2 - 18x + 12 = 0 \)
  3. Step 3: Simplify and Factorize the Quadratic Equation
    Divide the entire equation by 6:
    \( x^2 - 3x + 2 = 0 \)
    Factorizing: \( (x - 1)(x - 2) = 0 \)
    Therefore, \( x = 1 \) and \( x = 2 \).
  4. Step 4: Compute Corresponding y-values
    For \( x = 1 \): \( f(1) = 2(1)^3 - 9(1)^2 + 12(1) - 5 = 2 - 9 + 12 - 5 = 0 \)
    For \( x = 2 \): \( f(2) = 2(2)^3 - 9(2)^2 + 12(2) - 5 = 16 - 36 + 24 - 5 = -1 \)
Final Answer: Stationary Points are (1, 0) and (2, -1).
Topic 1: Stationary Points
Question 2: Find the stationary point for the two-variable function: \[ f(x, y) = 3x^2 + 2y^2 - 12x + 8y + 7 \]
Complete Step-by-Step Solution:
  1. Step 1: Calculate First Partial Derivatives
    Differentiate w.r.t \( x \) (treating \( y \) as constant):
    \( f_x = \frac{\partial f}{\partial x} = 6x - 12 \)
    Differentiate w.r.t \( y \) (treating \( x \) as constant):
    \( f_y = \frac{\partial f}{\partial y} = 4y + 8 \)
  2. Step 2: Set Each Partial Derivative to Zero
    Equation (1): \( 6x - 12 = 0 \implies 6x = 12 \implies x = 2 \)
    Equation (2): \( 4y + 8 = 0 \implies 4y = -8 \implies y = -2 \)
  3. Step 3: Calculate the Corresponding Function Value
    \( f(2, -2) = 3(2)^2 + 2(-2)^2 - 12(2) + 8(-2) + 7 \)
    \( = 3(4) + 2(4) - 24 - 16 + 7 = 12 + 8 - 24 - 16 + 7 = -3 \)
Final Answer: The Stationary Point is (2, -2) with value -3.

Question 3: Find the stationary points for the non-linear function: \[ f(x, y) = x^3 + y^3 - 3xy \]
Complete Step-by-Step Solution:
  1. Step 1: Compute Partial Derivatives
    \( f_x = 3x^2 - 3y \)
    \( f_y = 3y^2 - 3x \)
  2. Step 2: Set Equations to Zero
    1) \( 3x^2 - 3y = 0 \implies y = x^2 \)
    2) \( 3y^2 - 3x = 0 \implies x = y^2 \)
  3. Step 3: Solve System of Equations
    Substitute \( y = x^2 \) into equation (2):
    \( (x^2)^2 = x \implies x^4 - x = 0 \)
    \( x(x^3 - 1) = 0 \implies x = 0 \text{ or } x = 1 \)
    If \( x = 0 \implies y = (0)^2 = 0 \)
    If \( x = 1 \implies y = (1)^2 = 1 \)
Final Answer: Stationary Points are (0, 0) and (1, 1).
Topic 2: Relative Extrema

Topic Overview & Definition

Definition: Relative (Local) Extrema are local high points (Local Maxima) or local low points (Local Minima) relative to neighboring points in the domain.

Second Derivative Test (Single Variable):

  • If \( f'(x_0) = 0 \) and \( f''(x_0) > 0 \), then \( x_0 \) is a Relative Minimum.
  • If \( f'(x_0) = 0 \) and \( f''(x_0) < 0 \), then \( x_0 \) is a Relative Maximum.

Discriminant Test (Two Variables): Calculate Discriminant \( D = f_{xx}f_{yy} - (f_{xy})^2 \):

  • If \( D > 0 \) and \( f_{xx} > 0 \): Relative Minimum.
  • If \( D > 0 \) and \( f_{xx} < 0 \): Relative Maximum.
Topic 2: Relative Extrema
Question 1: Find and classify the relative extrema of: \[ f(x) = x^4 - 4x^3 + 10 \]
Complete Step-by-Step Solution:
  1. Step 1: First Derivative and Stationary Points
    \( f'(x) = 4x^3 - 12x^2 \)
    Set \( f'(x) = 0 \implies 4x^2(x - 3) = 0 \implies x = 0 \) or \( x = 3 \)
  2. Step 2: Calculate Second Derivative
    \( f''(x) = 12x^2 - 24x \)
  3. Step 3: Test Point \( x = 3 \)
    \( f''(3) = 12(3)^2 - 24(3) = 108 - 72 = 36 > 0 \)
    Since \( f''(3) > 0 \), \( x = 3 \) is a Relative Minimum.
    Value: \( f(3) = 3^4 - 4(3)^3 + 10 = 81 - 108 + 10 = -17 \)
  4. Step 4: Test Point \( x = 0 \)
    \( f''(0) = 0 \) (Inconclusive via 2nd derivative test; sign of \( f'(x) \) remains negative on both sides of 0, so no extremum at x=0).
Final Answer: Relative Minimum at (3, -17).
Topic 2: Relative Extrema
Question 2: Determine the relative extrema for the function: \[ f(x, y) = x^2 + xy + y^2 - 6x - 9y \]
Complete Step-by-Step Solution:
  1. Step 1: First Partial Derivatives
    \( f_x = 2x + y - 6 \)
    \( f_y = x + 2y - 9 \)
  2. Step 2: Solve System for Critical Point
    Set \( f_x = 0 \implies y = 6 - 2x \)
    Substitute into \( f_y = 0 \implies x + 2(6 - 2x) - 9 = 0 \)
    \( x + 12 - 4x - 9 = 0 \implies -3x + 3 = 0 \implies x = 1 \)
    Substitute back: \( y = 6 - 2(1) = 4 \). Critical Point = \( (1, 4) \).
  3. Step 3: Second Partial Derivatives & Discriminant
    \( f_{xx} = 2 \), \( f_{yy} = 2 \), \( f_{xy} = 1 \)
    \( D = f_{xx}f_{yy} - (f_{xy})^2 = (2)(2) - (1)^2 = 4 - 1 = 3 \)
  4. Step 4: Conclusion
    Since \( D = 3 > 0 \) and \( f_{xx} = 2 > 0 \), the point \( (1, 4) \) is a Relative Minimum.
    Value: \( f(1,4) = 1^2 + (1)(4) + 4^2 - 6(1) - 9(4) = 1 + 4 + 16 - 6 - 36 = -21 \)
Final Answer: Relative Minimum at (1, 4) with value -21.
Topic 2: Relative Extrema
Question 3: Find relative extrema for the multi-variable function: \[ f(x, y) = -x^2 - y^2 + 4x + 6y - 5 \]
Complete Step-by-Step Solution:
  1. Step 1: First Derivatives
    \( f_x = -2x + 4 = 0 \implies x = 2 \)
    \( f_y = -2y + 6 = 0 \implies y = 3 \)
    Critical Point = \( (2, 3) \)
  2. Step 2: Second Derivative Matrix Terms
    \( f_{xx} = -2 \), \( f_{yy} = -2 \), \( f_{xy} = 0 \)
  3. Step 3: Discriminant Calculation
    \( D = (-2)(-2) - (0)^2 = 4 - 0 = 4 > 0 \)
  4. Step 4: Classification
    Since \( D = 4 > 0 \) and \( f_{xx} = -2 < 0 \), the point \( (2,3) \) is a Relative Maximum.
    Value: \( f(2, 3) = -(2)^2 - (3)^2 + 4(2) + 6(3) - 5 = -4 - 9 + 8 + 18 - 5 = 8 \)
Final Answer: Relative Maximum at (2, 3) with value 8.
Topic 3: Saddle Points

Topic Overview & Definition

Definition: A saddle point is a critical point on a multi-variable surface \( f(x, y) \) where the function reaches a relative minimum in one direction, but a relative maximum in another direction. It is neither a local max nor a local min.

Mathematical Test:

Calculate Second-Order Partial Derivatives and the Hessian Discriminant:

\[ D = f_{xx} f_{yy} - (f_{xy})^2 \]
  • If \( D < 0 \) at a critical point, then that critical point is definitively a Saddle Point.
Topic 3: Saddle Points
Question 1: Identify all critical points and prove if any are saddle points for: \[ f(x, y) = x^2 - y^2 \]
Complete Step-by-Step Solution:
  1. Step 1: Find Critical Points
    \( f_x = 2x = 0 \implies x = 0 \)
    \( f_y = -2y = 0 \implies y = 0 \)
    Critical point is \( (0, 0) \).
  2. Step 2: Second Derivatives
    \( f_{xx} = \frac{\partial^2 f}{\partial x^2} = 2 \)
    \( f_{yy} = \frac{\partial^2 f}{\partial y^2} = -2 \)
    \( f_{xy} = \frac{\partial^2 f}{\partial x \partial y} = 0 \)
  3. Step 3: Evaluate Discriminant
    \( D = f_{xx} f_{yy} - (f_{xy})^2 = (2)(-2) - (0)^2 = -4 \)
  4. Step 4: Conclusion
    Since \( D = -4 < 0 \), the point \( (0, 0) \) is a Saddle Point.
Final Answer: Saddle Point exists at (0, 0).
Topic 3: Saddle Points
Question 2: Find the saddle point for the surface: \[ f(x, y) = 4xy - x^4 - y^4 \]
Complete Step-by-Step Solution:
  1. Step 1: First Partial Derivatives
    \( f_x = 4y - 4x^3 = 0 \implies y = x^3 \)
    \( f_y = 4x - 4y^3 = 0 \implies x = y^3 \)
  2. Step 2: Solve System
    Substitute \( y = x^3 \) into \( x = y^3 \):
    \( x = (x^3)^3 = x^9 \implies x^9 - x = 0 \implies x(x^8 - 1) = 0 \)
    Real roots: \( x = 0, x = 1, x = -1 \).
    Critical points: \( (0, 0) \), \( (1, 1) \), \( (-1, -1) \).
  3. Step 3: Second Derivatives & Discriminant Test
    \(f_{xx} = -12x^2\), \(f_{yy} = -12y^2\), \(f_{xy} = 4\)
    At \((0, 0)\): \(f_{xx} = 0, f_{yy} = 0, f_{xy} = 4\)
    \(D = (0)(0) - (4)^2 = -16 < 0 \implies\) Saddle Point.
Final Answer: Saddle Point is located at (0, 0) (Points (1,1) and (-1,-1) are local maxima).
Topic 3: Saddle Points
Question 3: Locate the saddle point of the function: \[f(x, y) = x^3 - 3x + y^2\]
Complete Step-by-Step Solution:
  1. Step 1: Find Critical Points
    \(f_x = 3x^2 - 3 = 0 \implies x^2 = 1 \implies x = 1 \text{ or } x = -1\)
    \(f_y = 2y = 0 \implies y = 0\)
    Critical Points are \((1, 0)\) and \((-1, 0)\).
  2. Step 2: Second Order Partials
    \(f_{xx} = 6x\), \(f_{yy} = 2\), \(f_{xy} = 0\)
  3. Step 3: Test Point \((-1, 0)\)
    \(f_{xx}(-1, 0) = 6(-1) = -6\)
    \(D = f_{xx} f_{yy} - (f_{xy})^2 = (-6)(2) - (0)^2 = -12\)
    Since \(D = -12 < 0\), \((-1, 0)\) is a Saddle Point.
Final Answer: Saddle Point is at (-1, 0) (while (1, 0) is a local minimum).
Topic 4: Lagrange Multipliers

Topic Overview & Definition

Definition: Lagrange Multipliers is a strategy for finding the local maxima and minima of a function subject to equality constraints.

Mathematical Formulation:

To optimize objective function \(f(x, y)\) subject to constraint \(g(x, y) = c\), introduce multiplier \(\lambda\) and define Lagrangian function:

\[L(x, y, \lambda) = f(x, y) - \lambda (g(x, y) - c)\]

Set gradient to zero vector: \(\nabla f = \lambda \nabla g\), leading to system:

  1. \(f_x = \lambda g_x\)
  2. \(f_y = \lambda g_y\)
  3. \(g(x, y) = c\)
Topic 4: Lagrange Multipliers
Question 1: Minimize \(f(x, y) = x^2 + y^2\) subject to the constraint equation \(2x + y = 10\).
Complete Step-by-Step Solution:
  1. Step 1: Set Up Gradient Equations (\(\nabla f = \lambda \nabla g\))
    Objective: \(f(x, y) = x^2 + y^2\)
    Constraint: \(g(x, y) = 2x + y = 10\)
    1) \(f_x = \lambda g_x \implies 2x = 2\lambda \implies x = \lambda\)
    2) \(f_y = \lambda g_y \implies 2y = \lambda(1) \implies y = \frac{\lambda}{2}\)
  2. Step 2: Express \(x\) in terms of \(y\)
    Since \(x = \lambda\) and \(y = \frac{\lambda}{2} \implies x = 2y\).
  3. Step 3: Substitute into Constraint Equation
    \(2(2y) + y = 10 \implies 4y + y = 10 \implies 5y = 10 \implies y = 2\)
    Since \(x = 2y \implies x = 2(2) = 4\).
  4. Step 4: Compute Minimum Function Value
    \(f(4, 2) = 4^2 + 2^2 = 16 + 4 = 20\)
Final Answer: Minimum value is 20 at (4, 2).
Topic 4: Lagrange Multipliers
Question 2: Maximize \(f(x, y) = xy\) subject to the constraint \(x + y = 8\).
Complete Step-by-Step Solution:
  1. Step 1: Lagrange Gradient Equations
    \(f_x = y\), \(g_x = 1 \implies y = \lambda(1) \implies \lambda = y\)
    \(f_y = x\), \(g_y = 1 \implies x = \lambda(1) \implies \lambda = x\)
  2. Step 2: Equate Multipliers
    \(x = y\)
  3. Step 3: Apply Constraint
    \(x + x = 8 \implies 2x = 8 \implies x = 4\)
    Since \(y = x \implies y = 4\).
  4. Step 4: Compute Maximum Value
    \(f(4, 4) = (4)(4) = 16\)
Final Answer: Maximum value is 16 at (4, 4).
Topic 4: Lagrange Multipliers
Question 3: Find the maximum value of \(f(x, y) = 4x + 2y\) subject to constraint \(x^2 + y^2 = 5\).
Complete Step-by-Step Solution:
  1. Step 1: Set Up System
    \(f_x = 4\), \(g_x = 2x \implies 4 = 2\lambda x \implies x = \frac{2}{\lambda}\)
    \(f_y = 2\), \(g_y = 2y \implies 2 = 2\lambda y \implies y = \frac{1}{\lambda}\)
  2. Step 2: Substitute into Constraint
    \(\left(\frac{2}{\lambda}\right)^2 + \left(\frac{1}{\lambda}\right)^2 = 5\)
    \(\frac{4}{\lambda^2} + \frac{1}{\lambda^2} = 5 \implies \frac{5}{\lambda^2} = 5 \implies \lambda^2 = 1 \implies \lambda = \pm 1\)
  3. Step 3: Evaluate Points
    For \(\lambda = 1 \implies x = 2, y = 1\).
    \(f(2, 1) = 4(2) + 2(1) = 10\)
    For \(\lambda = -1 \implies x = -2, y = -1\).
    \(f(-2, -1) = 4(-2) + 2(-1) = -10\)
Final Answer: Maximum value is 10 at (2, 1).
Topic 5: Maxima or Minima

Topic Overview & Definition

Definition: Maxima and Minima refer collectively to the highest (peak) and lowest (trough) values that a function attains within a given domain.

Absolute vs Relative:

  • Absolute Maximum/Minimum: The global highest or lowest value over the entire domain of the function.
  • Method of Determination: Find critical points using first derivative/partials, evaluate the 2nd derivative test or matrix, and compare function outputs.
Topic 5: Maxima or Minima
Question 1: Determine whether the function has a maximum or minimum, and find its value: \[f(x) = -3x^2 + 12x - 5\]
Complete Step-by-Step Solution:
  1. Step 1: First Derivative
    \(f'(x) = -6x + 12\)
  2. Step 2: Critical Point
    \(-6x + 12 = 0 \implies 6x = 12 \implies x = 2\)
  3. Step 3: Second Derivative Test
    \(f''(x) = -6\)
    Since \(f''(2) = -6 < 0\), the function has a Maximum at \(x = 2\).
  4. Step 4: Calculate Maximum Value
    \(f(2) = -3(2)^2 + 12(2) - 5 = -3(4) + 24 - 5 = -12 + 24 - 5 = 7\)
Final Answer: Function has a Maximum value of 7 at x = 2.
Topic 5: Maxima or Minima
Question 2: Find the absolute minimum value of the function: \[f(x, y) = 2x^2 + 3y^2 - 8x - 12y + 20\]
Complete Step-by-Step Solution:
  1. Step 1: Partial Derivatives
    \(f_x = 4x - 8 = 0 \implies x = 2\)
    \(f_y = 6y - 12 = 0 \implies y = 2\)
    Critical point is \((2, 2)\).
  2. Step 2: Second Partials & Discriminant
    \(f_{xx} = 4\), \(f_{yy} = 6\), \(f_{xy} = 0\)
    \(D = (4)(6) - (0)^2 = 24 > 0\).
    Since \(D > 0\) and \(f_{xx} = 4 > 0\), it is a Minimum.
  3. Step 3: Calculate Minimum Value
    \(f(2, 2) = 2(2)^2 + 3(2)^2 - 8(2) - 12(2) + 20\)
    \(= 2(4) + 3(4) - 16 - 24 + 20 = 8 + 12 - 16 - 24 + 20 = 0\)
Final Answer: Absolute Minimum value is 0 at (2, 2).
Topic 5: Maxima or Minima
Question 3: Find all local maxima and minima for: \[f(x) = x^3 - 6x^2 + 9x + 2\]
Complete Step-by-Step Solution:
  1. Step 1: Differentiate and Solve \(f'(x) = 0\)
    \(f'(x) = 3x^2 - 12x + 9 = 0\)
    Divide by 3: \(x^2 - 4x + 3 = 0 \implies (x - 1)(x - 3) = 0\)
    Critical points at \(x = 1\) and \(x = 3\).
  2. Step 2: Second Derivative Test
    \(f''(x) = 6x - 12\)
    At \(x = 1\): \(f''(1) = 6(1) - 12 = -6 < 0 \implies\) Local Maximum.
    At \(x = 3\): \(f''(3) = 6(3) - 12 = 6 > 0 \implies\) Local Minimum.
  3. Step 3: Evaluate Values
    Max Value at \(x = 1\): \(f(1) = 1^3 - 6(1)^2 + 9(1) + 2 = 6\)
    Min Value at \(x = 3\): \(f(3) = 3^3 - 6(3)^2 + 9(3) + 2 = 27 - 54 + 27 + 2 = 2\)
Final Answer: Local Maximum = 6 at x=1; Local Minimum = 2 at x=3.
