Overview & Fundamentals

Multivariable Optimization

Mastering Extreme Values (Maxima, Minima, Saddle Points) & Constrained Optimization using Lagrange Multipliers

Stationary Points

Points where all partial derivatives vanish simultaneously ($\nabla f = \mathbf{0}$). The tangent plane to the surface is completely horizontal at these locations.

Relative Extrema

Local Maximum: Peak where $f(x,y) \le f(a,b)$ nearby.
Local Minimum: Trough where $f(x,y) \ge f(a,b)$ nearby.

Saddle Points

A stationary point that is neither a maximum nor a minimum. The function increases along one direction and decreases along another direction.

Lagrange Multipliers

A powerful strategy for finding the local extrema of a function subject to equality constraints ($\phi(x,y,z)=0$) using gradient alignment $\nabla f = \lambda \nabla \phi$.

Algorithm: Maxima & Minima of 2 Variables

Standard Second-Derivative Test for $f(x, y)$

1

Find First Partial Derivatives

Compute $f_x = \frac{\partial f}{\partial x}$ and $f_y = \frac{\partial f}{\partial y}$.

2

Find Stationary Points

Solve the simultaneous system $f_x = 0$ and $f_y = 0$ to get critical points $(a, b)$.

3

Calculate Second Partial Derivatives

Evaluate at $(a, b)$: $r = f_{xx} = \frac{\partial^2 f}{\partial x^2}$, $s = f_{xy} = \frac{\partial^2 f}{\partial x \partial y}$, $t = f_{yy} = \frac{\partial^2 f}{\partial y^2}$.

4

Calculate Discriminant $D = rt - s^2$

  • If $rt - s^2 > 0$ and $r < 0$ (or $t < 0$) $\implies$ Local Maximum at $(a, b)$.
  • If $rt - s^2 > 0$ and $r > 0$ (or $t > 0$) $\implies$ Local Minimum at $(a, b)$.
  • If $rt - s^2 < 0$ $\implies$ Saddle Point at $(a, b)$.
  • If $rt - s^2 = 0$ $\implies$ Test Inconclusive (further analysis required).

Problem 1: Find the extreme values of $f(x, y) = x^2 + y^2 - 4x - 6y + 13$.
Step 1: First Partial Derivatives

$f_x = 2x - 4$, $\quad f_y = 2y - 6$.

Step 2: Stationary Points

Set $f_x = 0 \implies 2x - 4 = 0 \implies x = 2$.

Set $f_y = 0 \implies 2y - 6 = 0 \implies y = 3$.

Stationary Point: $(2, 3)$.

Step 3: Second Partial Derivatives

$r = f_{xx} = 2$, $\quad s = f_{xy} = 0$, $\quad t = f_{yy} = 2$.

Step 4: Classification & Conclusion

$D = rt - s^2 = (2)(2) - (0)^2 = 4 > 0$.

Since $D > 0$ and $r = 2 > 0$, the point $(2, 3)$ is a Minimum.

Minimum Value: $f(2,3) = (2)^2 + (3)^2 - 4(2) - 6(3) + 13 = 0$.

Problem 2: Examine $f(x, y) = x^3 + y^3 - 3xy$ for maxima and minima.
Step 1: First Partial Derivatives

$f_x = 3x^2 - 3y$, $\quad f_y = 3y^2 - 3x$.

Step 2: Stationary Points

$3x^2 - 3y = 0 \implies y = x^2$. Substitute into $3y^2 - 3x = 0$:

$(x^2)^2 - x = 0 \implies x(x^3 - 1) = 0 \implies x = 0$ or $x = 1$.

Points: $(0, 0)$ and $(1, 1)$.

Step 3: Second Derivatives

$r = f_{xx} = 6x$, $\quad s = f_{xy} = -3$, $\quad t = f_{yy} = 6y$.

Step 4: Classification

At $(0,0)$: $r=0, s=-3, t=0 \implies D = 0 - (-3)^2 = -9 < 0$ $\rightarrow$ Saddle Point.

At $(1,1)$: $r=6, s=-3, t=6 \implies D = (6)(6) - (-3)^2 = 27 > 0$, $r=6 > 0$ $\rightarrow$ Minimum.

Min Value: $f(1,1) = 1 + 1 - 3 = -1$.

Problem 3: Investigate $f(x, y) = x^2 - y^2$.
Step 1: First Derivatives

$f_x = 2x = 0 \implies x = 0$. $f_y = -2y = 0 \implies y = 0$. Critical Point: $(0,0)$.

Step 2: Second Derivatives

$r = f_{xx} = 2$, $s = f_{xy} = 0$, $t = f_{yy} = -2$.

Step 3: Conclusion

$D = rt - s^2 = (2)(-2) - 0 = -4 < 0$.

Therefore, $(0,0)$ is a Saddle Point.

Problem 4: Find extreme values of $f(x, y) = 4 + x^3 + y^3 - 3xy$.
Step 1: Critical Points

$f_x = 3x^2 - 3y = 0$, $f_y = 3y^2 - 3x = 0$. Stationary points: $(0,0)$ and $(1,1)$.

Step 2: Evaluation

At $(0,0)$: $D = -9 < 0$ (Saddle Point).

At $(1,1)$: $r=6, t=6, s=-3 \implies D = 27 > 0, r > 0 \implies$ Local Minimum.

Problem 5: Find stationary points of $f(x, y) = xy e^{-(x^2+y^2)/2}$.
Step 1: First Partial Derivatives

$f_x = y(1 - x^2)e^{-(x^2+y^2)/2} = 0$, $\quad f_y = x(1 - y^2)e^{-(x^2+y^2)/2} = 0$.

Algorithm: Maxima & Minima of 3 Variables

Using the Hessian Matrix & Principal Minor Determinants

1. The Hessian Matrix ($H$)

Construct the matrix of second-order partial derivatives evaluated at critical point $(x_0, y_0, z_0)$ where $f_x = f_y = f_z = 0$:

$$H = \begin{pmatrix} f_{xx} & f_{xy} & f_{xz} \\ f_{yx} & f_{yy} & f_{yz} \\ f_{zx} & f_{zy} & f_{zz} \end{pmatrix}$$

2. Principal Minors Test

$$\Delta_1 = f_{xx}, \quad \Delta_2 = \begin{vmatrix} f_{xx} & f_{xy} \\ f_{yx} & f_{yy} \end{vmatrix}, \quad \Delta_3 = \det(H)$$

  • Local Minimum (Positive Definite): $\Delta_1 > 0, \quad \Delta_2 > 0, \quad \Delta_3 > 0$.
  • Local Maximum (Negative Definite): $\Delta_1 < 0, \quad \Delta_2 > 0, \quad \Delta_3 < 0$ (Alternating signs).
  • Saddle Point (Indefinite): Non-zero determinants that fail both conditions above.

Lagrange Multipliers: 2 Variables Theory

Optimizing $f(x, y)$ subject to constraint $\phi(x, y) = 0$

1. Geometric Intuition

At an extreme point on the constraint curve $\phi(x, y) = 0$, the gradient vector $\nabla f$ is parallel to the gradient vector $\nabla \phi$.

$$\nabla f(x, y) = \lambda \nabla \phi(x, y)$$

2. Lagrange Auxiliary Function

Define the combined function $F(x, y, \lambda)$:

$$F(x, y, \lambda) = f(x, y) + \lambda \cdot \phi(x, y)$$

3. System of Equations to Solve

Set all partial derivatives equal to zero:

$$\frac{\partial F}{\partial x} = f_x + \lambda \phi_x = 0$$

$$\frac{\partial F}{\partial y} = f_y + \lambda \phi_y = 0$$

$$\frac{\partial F}{\partial \lambda} = \phi(x, y) = 0$$

5 Solved Examples: Lagrange (2 Variables)

Step-by-step solutions

Problem 1: Find the minimum of $f(x, y) = x^2 + y^2$ subject to $x + y = 2$.
Step 1: Set up Lagrange Function

$F(x, y, \lambda) = x^2 + y^2 + \lambda(x + y - 2)$.

Step 2: Take Partial Derivatives

$F_x = 2x + \lambda = 0 \implies x = -\lambda / 2$

$F_y = 2y + \lambda = 0 \implies y = -\lambda / 2$

Thus, $x = y$.

Step 3: Solve via Constraint

Substitute $x = y$ into $x + y = 2 \implies 2x = 2 \implies x = 1, y = 1$.

Step 4: Final Answer

Minimum point: $(1, 1)$.

Minimum Value: $f(1, 1) = 1^2 + 1^2 = 2$.

Problem 2: Maximize $f(x, y) = 3x + 4y$ on the circle $x^2 + y^2 = 25$.
Step 1: System

$3 + 2\lambda x = 0 \implies x = -3/(2\lambda)$

$4 + 2\lambda y = 0 \implies y = -4/(2\lambda) \implies y = \frac{4}{3}x$.

Step 2: Solve & Substitute

$x^2 + (16/9)x^2 = 25 \implies (25/9)x^2 = 25 \implies x = \pm 3, y = \pm 4$.

Max Value at $(3, 4)$: $f(3,4) = 3(3) + 4(4) = 25$.

Problem 3: Maximize $f(x, y) = xy$ subject to $2x + 3y = 12$.
Step 1: Equations

$y + 2\lambda = 0$, $x + 3\lambda = 0 \implies \lambda = -y/2 = -x/3 \implies 2x = 3y$.

Step 2: Conclusion

$3y + 3y = 12 \implies y = 2, x = 3$.

Max Value: $f(3, 2) = 6$.

Problem 4: Find closest point on line $x + 2y = 5$ to origin $(0,0)$.
Step 1: Minimize $D = x^2 + y^2$

$2x + \lambda = 0$, $2y + 2\lambda = 0 \implies y = 2x$.

Step 2: Solve

$x + 2(2x) = 5 \implies 5x = 5 \implies x = 1, y = 2$. Point $(1, 2)$.

Problem 5: Maximize area $A = xy$ of rectangle with fixed perimeter $2x + 2y = P$.
Step 1: Lagrange Equations

$y + 2\lambda = 0$, $x + 2\lambda = 0 \implies x = y$.

Step 2: Result

$2x + 2x = P \implies x = y = P/4$ (A square maximizes area!).

Lagrange Multipliers: 3 Variables Theory

Optimizing $u = f(x, y, z)$ subject to $\phi(x, y, z) = 0$

Lagrange Function Definition

Construct the auxiliary function $F(x, y, z, \lambda)$:

$$F(x, y, z, \lambda) = f(x, y, z) + \lambda \cdot \phi(x, y, z)$$

System of Equations

Set gradient to zero $\nabla F = \mathbf{0}$:

$\frac{\partial F}{\partial x} = f_x + \lambda \phi_x = 0$
$\frac{\partial F}{\partial y} = f_y + \lambda \phi_y = 0$
$\frac{\partial F}{\partial z} = f_z + \lambda \phi_z = 0$
$\phi(x, y, z) = 0$

Standard Proof Template: $u = x^2 + y^2 + z^2$ s.t. $ax + by + cz = p$

1. $2x + a\lambda = 0 \implies x = -a\lambda/2$
2. $2y + b\lambda = 0 \implies y = -b\lambda/2$
3. $2z + c\lambda = 0 \implies z = -c\lambda/2$
4. Plug into constraint: $-\frac{\lambda}{2}(a^2+b^2+c^2) = p \implies \lambda = -\frac{2p}{a^2+b^2+c^2}$
5. Stationary Value: $$\mathbf{u = \frac{p^2}{a^2 + b^2 + c^2}}$$

5 Solved Examples: Lagrange (3 Variables)

Step-by-step solutions

Problem 1: Find stationary value of $u = x^2 + y^2 + z^2$ subject to $ax + by + cz = p$.
Step 1: Partial Derivatives

$2x + a\lambda = 0 \implies x = -a\lambda / 2$

$2y + b\lambda = 0 \implies y = -b\lambda / 2$

$2z + c\lambda = 0 \implies z = -c\lambda / 2$

Step 2: Substitute into Constraint

$a(-a\lambda/2) + b(-b\lambda/2) + c(-c\lambda/2) = p$

$\implies -\frac{\lambda}{2}(a^2 + b^2 + c^2) = p \implies \lambda = -\frac{2p}{a^2+b^2+c^2}$.

Step 3: Point Coordinates

$x = \frac{ap}{a^2+b^2+c^2}, \quad y = \frac{bp}{a^2+b^2+c^2}, \quad z = \frac{cp}{a^2+b^2+c^2}$.

Step 4: Final Value

$$u = \frac{a^2 p^2 + b^2 p^2 + c^2 p^2}{(a^2+b^2+c^2)^2} = \mathbf{\frac{p^2}{a^2 + b^2 + c^2}}$$

Problem 2: Maximize $u = x + 2y + 3z$ on sphere $x^2 + y^2 + z^2 = 14$.
Step 1: System

$1 + 2\lambda x = 0$, $2 + 2\lambda y = 0$, $3 + 2\lambda z = 0 \implies y = 2x, z = 3x$.

Step 2: Solve & Max Value

$x^2 + 4x^2 + 9x^2 = 14 \implies 14x^2 = 14 \implies x = 1, y = 2, z = 3$.

Max Value = $1 + 4 + 9 = 14$.

Problem 3: Maximize box volume $V = xyz$ with fixed surface area $2(xy + yz + zx) = 12$.
Step 1: Symmetry Argument

By symmetry in $x, y, z$, $x = y = z$ at maximum.

Step 2: Calculation

$2(3x^2) = 12 \implies 6x^2 = 12 \implies x = y = z = \sqrt{2}$.

Max Volume $V = (\sqrt{2})^3 = 2\sqrt{2}$.

Problem 4: Maximize $u = xyz$ subject to $x + y + z = 30$.
Step 1: Equations

$yz = \lambda$, $xz = \lambda$, $xy = \lambda \implies x = y = z$.

Step 2: Conclusion

$3x = 30 \implies x = y = z = 10$.

Max Value $u = 10 \times 10 \times 10 = 1000$.

Problem 5: Find min distance from origin to plane $x + 2y + 2z = 9$.
Step 1: Square Distance $D = x^2 + y^2 + z^2$

$2x = \lambda, 2y = 2\lambda, 2z = 2\lambda \implies y = 2x, z = 2x$.

Step 2: Point & Distance

$x + 4x + 4x = 9 \implies 9x = 9 \implies x = 1, y = 2, z = 2$.

Min Distance $\sqrt{1^2 + 2^2 + 2^2} = 3$.

Formula Cheat Sheet & Quick Summary

Key Discriminants & Master Equations

2-Variable Discriminant ($rt - s^2$)

  • $rt - s^2 > 0, r > 0$: Local Minimum
  • $rt - s^2 > 0, r < 0$: Local Maximum
  • $rt - s^2 < 0$: Saddle Point
  • $rt - s^2 = 0$: Inconclusive

3-Variable Hessian Minors

  • $\Delta_1 > 0, \Delta_2 > 0, \Delta_3 > 0$: Minimum
  • $\Delta_1 < 0, \Delta_2 > 0, \Delta_3 < 0$: Maximum
  • Other Non-zero: Saddle Point

Master Lagrange Result

For $u = x^2 + y^2 + z^2$ subject to $ax + by + cz = p$:

$$u_{min} = \frac{p^2}{a^2 + b^2 + c^2}$$
